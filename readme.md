These are implementation of Relvent Supervised Models, builtin Python From **Scratch**. Took me around 2-3 Months but it was fun, *yay*

The models implemented contains:

- Linear Regression
- Logistic Regression
- KNN
- Decision Tree
- Random Forest
- SVM
- Neural Network

You will find the models code in `models/` and it's usage in `usage/`
